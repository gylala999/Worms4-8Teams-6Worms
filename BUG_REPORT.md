# Bug report details

Open an Issue at https://github.com/gylala999/Worms4-8Teams-6Worms/issues and include:

- Mod version (for example v33) and whether you used the published ZIP or built source.
- Map name, rules and every active Wormpot bonus.
- Human/CPU selection and worm count for each of Teams 1–8.
- Round number and the exact weapon or action just before the problem.
- Expected behavior and actual behavior, including which team was targeted/eliminated.
- Reproduction steps and how often it occurs.
- Whether the launcher reported successful original-file restoration.
- A screenshot/video and relevant result/session/native-crash text, if available.

Keep the launcher open after a crash until restoration finishes. Use Open test logs, add notes, and Make report ZIP to preserve your run locally. Reports are never sent automatically.

Before posting, remove personal paths or other private information. Do not attach memory dumps, original game files, original backups or save data to public Issues. If a report ZIP includes diagnostic memory excerpts, review it before sharing.

Reports are welcome. The maintainer may need more reproduction details; fixes are not guaranteed for every report.
